## 2. Supply Chain Inventory System

### Description
A database designed to manage supply chain and inventory operations.  
It tracks customers, employees, products, orders, warehouses, and regions.

### Tables
- **customer** – Customer details and credit limits  
- **employee** – Employee information  
- **product** – Product catalog  
- **orders** – Customer orders  
- **orderdetails** – Line items of each order  
- **warehouse** – Warehouse locations  
- **region** – Geographical regions  

### Key Features
- Customer and employee management  
- Product and inventory tracking  
- Order processing with order details  
- Multi-warehouse and region support  

### How to Use
1. Open MySQL Workbench or any MySQL client  
2. Create a new schema (optional)  
3. Run the `supplychain.sql` file to import the complete database
